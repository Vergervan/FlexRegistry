# Менеджер реестров

Локальное WPF-приложение для ведения картотеки: сущности с **своей схемой полей**, текстовыми заметками и вложенными файлами. Данные хранятся в файле **LiteDB** (`.db`), при желании — с паролем.

Изначально задумывалось как реестр людей, но схема не жёсткая: в настройках задаются ключи полей (обязательные и дополнительные), и ту же базу можно использовать для техники, дел, контактов или любой другой однотипной коллекции.

## Возможности

- Несколько баз: создание, подключение существующего `.db`, отображаемое имя в списке (`config.ini`)
- Опциональное шифрование файла базы паролем (встроенный механизм LiteDB)
- Схема записи: базовые поля с флагами "обязательное" и "видимое в списке"; у конкретной карточки — произвольные дополнительные пары ключ–значение
- Заметки с датами создания и изменения
- Вложения через LiteDB FileStorage: добавление, открытие, экспорт, удаление
- Поиск по значениям полей (Enter в строке поиска; ранжирование по числу совпадений)
- Массовый импорт из Excel (`.xls` / `.xlsx`): колонки с именами базовых полей попадают в схему, остальные — в дополнительные поля

## Стек

- .NET Framework 4.7.2, WPF
- [LiteDB](https://www.litedb.org/) 5
- ExcelDataReader, Costura.Fody (зависимости вшиваются в exe)

## Запуск

Нужны Visual Studio с рабочей нагрузкой для классического .NET Framework / WPF и установленный .NET Framework 4.7.2.

```text
открыть FlexRegistry.csproj → восстановить NuGet → собрать → запустить
```

При первом старте создайте базу (при необходимости с паролем) или подключите уже существующий `.db`. Перед работой задайте **базовые поля** в "Настройки" — без них карточки не имеют общей структуры.

## Модель данных (одна база)


| Коллекция      | Назначение                               |
| -------------- | ---------------------------------------- |
| `settings`     | Схема базовых полей                      |
| `persons`      | Карточки (поля — списки `Key` / `Value`) |
| `records`      | Заметки, привязанные к карточке          |
| `file_records` | Метаданные вложений                      |
| FileStorage    | Содержимое файлов                        |


Список известных баз хранится рядом с exe в `config.ini`. Открытые вложения временно кладутся в скрытую папку `Temp` в каталоге приложения.
